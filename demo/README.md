# Windows 壁纸助手 · 交互 Demo

由 `LU55l`（锁屏）与 `r5F9TT`（桌面挂件）两个画板稿生成的可交互网页 Demo，
零依赖、无需构建，直接用浏览器打开即可。

## 运行

```bash
cd "…/bbb6af22-9bfa-48d9-b303-c096f0588821"
python3 -m http.server 8765
```

打开 <http://localhost:8765/demo/index.html>

> 需用 http 服务打开：壁纸与字体通过相对路径加载，`file://` 下会被浏览器拦截。
> 默认进入锁屏。深链参数：`?s=desktop` 直接进入桌面、`?wall=2` 直接定位到某张壁纸、`?app=1` 走一遍客户端唤起过程（`?app=scroll` 直接落在壁纸轮播设置页）、`?menu=1` 让「设为 …」菜单默认展开（便于对照设计稿）。

所有操作反馈都以 toast 呈现：**屏幕正中央、只有一行文字**，无图标、无圆点。

## 交互

| 位置 | 操作 | 效果 |
| --- | --- | --- |
| 顶部胶囊 | 锁屏 / 桌面 | 切换两个界面，也支持 `←` `→` 方向键 |
| 锁屏 · 键盘 `Esc` | 关闭锁屏 | 锁屏是一层蒙布：按 `Esc` → **关闭锁屏、进入桌面**（和「更多美图」一样落到桌面，但不唤起客户端）。桌面上的 `Esc` 仍是原语义（关窗），两者互不干扰 |
| 锁屏 · 点击非控件处 | 关闭锁屏 | 点壁纸、时钟区等**任何非控件处**同样**关闭锁屏、进入桌面**。只有真正的控件不触发：三枚胶囊、「设为 …」菜单、小组件卡片（天气 / 日历 / 热门壁纸）整体、以及卡片里的按钮与壁纸格子 |
| 锁屏 · 右上操作区（`A1x0f`） | 光标行为 | **默认隐藏**：刚进锁屏、或光标静止 3s，三枚胶囊（显示切换 / 设为 … / 更多美图）整体淡出。隐身只压 **`opacity`，不再用 `visibility` 屏掉**：胶囊隐身时**照样能点得到**，点的第一下会把整行唤出来；否则点击会穿到底下的壁纸，被当成「点空白」直接掀掉锁屏。光标一动（`mousemove` / `mousedown` / 滚轮）淡入。光标停在胶囊上、Tab 焦点还留在胶囊上、或「设为 …」菜单开着时**不倒计时**；离开后重新 3s。从桌面回锁屏会重新回到隐藏态 |
| 锁屏 · 右上操作区 · 可点区 | 点击 | 三枚胶囊只有 38px 高、显示切换只有 47px 宽，且紧贴画布右上角——贴着它点偏几像素就落到壁纸上。所以容器自带一圈**看不见的安全边**（`padding`：左 / 下各 12px，上 / 右 20px 直抵画布边缘），胶囊视觉位置一点没动（仍是 `1283,20`）。**右上角整块都算控件**，不是「空白」 |
| 锁屏 · 显示切换 | 点击 | 显示 / 隐藏**锁屏小组件行**（天气 / 日历 / 热门壁纸），壁纸本身不变；图标 `eye` ↔ `eye-off`。这是**锁屏特有**的一枚 |
| 锁屏 · 设为 … | 悬停或点击 | 弹出菜单：设为桌面 / 设为锁屏 / 同时设为。菜单**默认无高亮**，悬停到某项才出现 `Wnfn4` 的悬停样式 |
| 锁屏 · 更多美图 | 点击 | **退出锁屏 → 进入桌面 → 客户端启动页 → 内容就位**（`yKmw8`），全过程 760ms |
| 锁屏 · 查看更多 | 点击 | `BMgDr`「今日精选」胶囊，与「更多美图」同一入口 |
| 锁屏 · 热门壁纸 | 悬停 / 点击 | **每张卡片各自独立**：悬停时该格图片在圆角内轻微放大（1.09）并开始播放**它自己**的动态壁纸预览（同一时刻只跑一个），无阴影、无位移；点击进入**该张壁纸自己的详情页**（`ia7Oi` / `appDetail`），标题、预览、相关壁纸都换成这一张 |
| 锁屏 · 更多美图（叠影） | 悬停 | `JqKql` 三格就是**那三张动态壁纸**，静态时三张封面静帧；悬停**三格同时播放**（三者 `currentTime` 严格同步），移开全部暂停、落回封面 |
| 锁屏 · 日历 | 上 / 下翻页 | 按周翻页，今天高亮 |
| 桌面 · 系统托盘（`G7FiM`） | 无 | **只展示、没有任何反馈效果**：无 hover 态、无按压态、无光标手型、不可聚焦、无 toast，也不参与「点窗口外关窗」的判定 |
| 桌面 · 壁纸助手 | 轮播行（`XYyAA`） | **控制行共两枚暂停，语义完全不同**（画板：`Yh8yK` 的 `lFSyE` / `s15bM` / `Q0yADS` / `YLcPB`，导航组里 `Ai7Vr` / `e5w4OC` / `UhJQV`）|
| 桌面 · 壁纸助手 | 视频开关（`s15bM`）| 图标用 Lucide **`video` / `video-off`**，而不是 `play` / `pause` —— 否则它暂停时的恢复图标会和轮播那枚（`play`）撞成同一个，两枚按钮看着一模一样。它只管视频本身：关掉后画面停在当前帧，`toast`「视频已关闭 / 视频已开启」，与轮播是否停止**无关** |

| 桌面 · 壁纸助手 | 轮播行 · 上一张 / 下一张 | **动态壁纸下**只在六张 MP4 动态壁纸里循环，不会跑到静态壁纸上；缩略图跟着当前壁纸换。`Ai7Vr` / `UhJQV` 这两枚**不弹 toast**（整屏壁纸当场就换，提示是噪声），只靠缩略图 + 画面反馈 |
| 桌面 · 壁纸助手 | 轮播行 · 关闭动态壁纸后 | 行本身照常展示，**文案不做差异化**：名称 `壁纸轮播`、说明 `30 分钟自动切换` / `已暂停` 都是通用文案（说明节点 `ckzCC` 不属于静态态专属），只有缩略图跟当前静态壁纸、上一张 / 下一张改在**九张静态壁纸里翻牌**。所以上一张 / 下一张**无论哪种模式都在**，不会没反应 |
| 桌面 · 壁纸助手 | 排行榜（`rjDsr` + `MBuYL`）| 与锁屏「热门壁纸」同一套设计：三格横排 + 排名角标，**两行共六格**（`images/` 下六个 MP4 全部出场）。**每格独立**——悬停该格只播它自己的动态壁纸预览（同一时刻只跑一个），点击进入该张壁纸自己的详情页（`ia7Oi` / `appDetail`）。**通用模块，不做静态壁纸差异化**，关闭动态壁纸后照旧展示这六格 |

## 动态壁纸

`images/` 下的**六个 MP4** 全部作为动态壁纸素材接入：

| 素材 | 名称 | 出现位置 |
| --- | --- | --- |
| `4153410-uhd_3840_2160_25fps.mp4` | 叠纸暖阳 | 排行榜 ① / 轮播、热门壁纸 ①、更多美图叠影 |
| `7565825-hd_2048_1080_25fps.mp4` | 紫墨流云（PRO） | 排行榜 ② / 轮播、热门壁纸 ②、更多美图叠影 |
| `8303104-hd_1920_1080_24fps.mp4` | 鎏金缎带 | 排行榜 ③ / 轮播、热门壁纸 ③、更多美图叠影 |
| `11368306-hd_1920_1080_30fps.mp4` | 虹彩流光 | 排行榜 ④ / 轮播（第二行第一格） |
| `12472758_1920_1080_24fps.mp4` | 日落剪影 | 排行榜 ⑤ / 轮播（第二行第二格） |
| `4405733-hd_1920_1080_25fps.mp4` | 暮色之城 | 排行榜 ⑥ / 轮播（第二行第三格） |

- 挂件里的排行榜（`rjDsr` + `MBuYL`，画板上两行三格 = `a-rank-wrap` 里两个 `.a-rank`）铺满六个 MP4；锁屏「热门壁纸」仍是设计稿里的三格，取前三个。
- 轮播行上一张 / 下一张（`goDynamic`）在**这六个**里循环，锁屏/桌面/挂件缩略图跟着换。

- 选中动态壁纸时，`#lockWp` / `#deskWp` 里会挂一个 `object-fit:cover` 的 `<video loop muted playsinline>` 铺满 1600×1000；静图壁纸则回落到 `background-image`。
- **只有当前可见的那一屏播放**：`setScreen()` 会重新 `render()`，另一屏自动卸载 `<video>` 并显示封面静帧，避免两个 1600×1000 视频同时解码。
- 缩略图（热门壁纸 / 排行榜 / 更多美图叠影 / 轮播行缩略图）一律使用视频封面：`assets/v1…v6.jpg` 由 `qlmanage` 抽帧、`sips` 压成 900px JPEG（同一份也放在 `../images/` 下，供画板的 .pen 使用）。
- **热门壁纸悬停即播放该格的预览**：`.rank-tile` 内嵌一个 `preload="metadata"` 的 `<video class="rank-vid">`，`mouseenter` 时 `play()`、`mouseleave` 时 `pause()`，并在封面之上 220ms 淡入（两层一起 zoom 1.09）。`hoverVid` 保证同一时刻只跑一个，不会三格齐播。
- 浏览器拦截带声自动播放时会自动退回静音播放，保证画面一定在动。

任意入口换壁纸后，锁屏、桌面、挂件缩略图会同步更新——用来直观看「同一次换壁纸」的完整链路。

- 深链 `?static=N` 可直接进入静态壁纸态并定位到第 N 张（0 基，0…8）。

桌面图标（`RtmAE`）与任务栏（`fjrXH`，内含**系统托盘 `G7FiM`**：展开 / 网络 / 音量 / 电池 + 时钟）按设计稿只做**静态站位展示**，不含任何交互。
**系统托盘 `G7FiM` 是纯展示，没有任何反馈效果**：四枚图标与时钟在 demo 里用 `<span class="tray-item">` 而不是 `<button>`（否则会吃到全局 `button{cursor:pointer}`，悬停时手型光标就是一种会让人以为能点的反馈），无 hover 底色、无按压态、`tabIndex=-1` 不可聚焦、无 toast；点它也不算「点窗口外」，**不会**把已打开的壁纸库窗口关掉（走 `#screenDesktop` 的点击白名单）。

## 结构

- `index.html` — 全部内容（结构 / 样式 / 逻辑 / 内联 Lucide 图标）
- `assets/` — 本地化的壁纸（含新增五张 `wall-fjord / canyon / falls / sequoia / surf.jpg`）、缩略图，以及六个视频封面 `v1…v6.jpg`（后三个同时复制到 `../images/` 供画板使用）
- `../images/` — 设计稿自带的壁纸 `image.png` 与 D-DIN 字体

设计参数与画板保持一致：1600×1000 画布、玻璃材质 `#0000004D` + 1px `#FFFFFF24` + 12px 模糊、
圆角 20 / 999、时间 128px D-DIN、挂件 322×126、壁纸助手挂件 `llYsS` **380**（内容区 340）等。

> 画板里描边默认不计入 `width`，而 CSS 的 `1px` 边框在 `box-sizing:border-box` 下会占掉内容区 —— 所以胶囊的 `padding` 各减 1px（如更多美图 `0 12px 0 7px` → `0 11px 0 6px`），保证整体仍严格等于 297×38。
>
> 同一条规则也适用于卡片与挂件：`.card`（322，设计 `pad[16,20]`）与 `.assist`（380，同）左右内边距都用 **19px**，内容区才回到设计的 **282 / 340**（否则被描边吃掉 2px，三格一行会变成 89.33 而不是 90）。

`A1x0f`（右上操作区）与 `kTmpc`（设为菜单）额外对齐了卡片的隐藏参数：

- 右侧三个胶囊是**三个独立元素**，不是一根整条 —— 容器 `A1x0f` 自身透明无描边，尺寸 297×38（`297 = 47 + 8 + 75 + 8 + 159`）只负责定位；
- 显示切换 `47×38` `#0000004D` / `#FFFFFF24`，设为分组 `75×38` `#00000059` / `#FFFFFF3D`，更多美图 `159×38` `#0000004D` / `#FFFFFF24`（`TKJvj` 常态就比左右两枚更亮一档，**不是** hover 才变亮）；
- 三者阴影统一为 `0 8px 26px #0000001a`，圆角 999；
- 叠影三张图为 26px 圆形、白描边 `#FFFFFF3D`，x = 0 / 17 / 34（60×26 内重叠）；三格的素材就是那三张动态壁纸（不是另找的三张图）；
- **悬停行为的两种语义要分开**：热门壁纸是**单例**（同一时刻只跑一个，`hoverVid` 互斥）；更多美图的叠影是**全开**（三格同时播，不进 `hoverVid`，两边互不干扰）；
- `设为 …` 三个字 13px，左右各 16 内边距 → 胶囊宽正好 75；
- 设为菜单 113×118，内边距 6、行间距 2，行高 34；行默认 `radius 10` / 无底色，**悬停**才套用 `Wnfn4` 的样式：底色 `#FFFFFF1F` + 圆角 16 + 图标由 `#FFFFFFC4` 转 `#FFFFFF`；
- 库页 / 详情页的**窗口外点击**要放过右上角那枚入口与浮窗本身（`#deskToggle`、`#deskAssist`），否则一点浮窗就被当成「点窗口外」把窗口关掉；
- **锁屏是一层蒙布，`Esc` 和点空白都能掀开**：`dismissLock()` → `setScreen('desktop')`。键盘上是「先判屏、再判窗口」：`state.screen === 'lock'` 时 `Esc` 只关锁屏、不去动客户端窗口（锁屏上本来也开不了窗口）；在桌面上才走 `closeApp()`。点击侧用白名单排除真控件（`button, a, .rank-tile, .ops, #setMenu, #lockWidgets`），所以点胶囊、点卡片、翻日历都不会误退锁屏；
- **判断「点的是不是控件」一律走 `inControl(e, sel)`，不能用 `e.target.closest(sel)`**（`publish` 与 `demo` 同源）。两处会踩同一个坑：① 胶囊自己的 click 处理会 `innerHTML = icon(...)` 换图标（`eye` ↔ `eye-off`），把 `e.target` 那个 `svg` **从树上摘下来**，事件往上冒到 `#screenLock` 时 `closest('button')` 已经返回 `null`，一次干净的按钮点击被判成「点空白」→ 直接退出锁屏（这正是「显示切换容易触发退锁屏」的真因，只有胶囊的空白边缘碰巧没事）；② 桌面那枚「壁纸入口」有同样的换图标行为，会导致点图标把壁纸库窗口关掉。`composedPath()` 在事件派发那一刻就固定了路径，不受后续 DOM 改动影响；
- **「哪个屏上的东西能点」必须由 `pointer-events` 一起管住，不能只看控件自己的状态**：`.screen{pointer-events:none}` / `.screen.on{pointer-events:auto}` 只管住**屏自己**，而后代里任何一条 `pointer-events:auto` 都会盖掉祖先的 `none`。所以三条「重新开可点」的规则都带上 `.screen.on` 前缀：`.screen.on .desk-app.on, .screen.on .desk-app.on .app-view.on, .screen.on .menu.on`。否则从壁纸详情页 `J6TeyX` / 壁纸轮播设置 `TsJZR` 里的「唤起屏保」进锁屏后，壁纸库窗口虽然已经切走（`opacity:0`），仍留在原地 `270,160 1060×680`（下沿到 840）继续吃点击，把锁屏底部小组件行（`y 750+`）上的**日历卡片 `kGynP` 与热门壁纸卡片 `lCFNd`** 整块挡住 —— 点上一周 / 下一周、点缩略图全都没反应；同理，锁屏上开着没关的「设为 …」菜单也会隔着屏吃掉桌面上的点击。注意窗口这时仍然**不关**（`state.appPhase` 保持 `open`，掀掉锁屏后窗口和页面都还在原样），只是不再接收点击；
- **两枚「显示切换」是两个不同的功能**，不要混同：锁屏那枚（`ZC5g7`，`eye`）是显示 / 隐藏小组件行；桌面那枚（`T5sB3w`，`gallery-horizontal-end`）是**壁纸入口**，悬停展开壁纸助手挂件；
- 热门壁纸缩略图悬停只在圆角内放大图片（`scale(1.09)`，`cubic-bezier(.22,.61,.36,1)` 340ms），不加阴影、不做位移；
- 标题行右侧的「查看更多」胶囊**只有一种规格**：`BMgDr`（锁屏热门壁纸卡片）/ `UcQCx`（挂件壁纸频道）/ `DqAiM` 等四处入口浮窗里同名的那枚 —— 五处全部 56×21、字号 10、内边距 `4/8`、`#FFFFFF1F`、`r999`，悬停时底色提到 `#FFFFFF33` 并转为纯白文字；
- **锁屏默认壁纸就是动态壁纸**：`WALLS[1]`（叠纸暖阳）打了 `default:true`，`DEFAULT_WALL` 由它推导，锁屏首屏即播 MP4；
- **客户端窗口有三个互斥视图**，由 `state.appView` 驱动：`app-lib`（壁纸库首页，`images/image-1.png`，对应 `QNMlM`）/ `app-detail`（单张壁纸详情，`images/image-2.png`，对应 `ia7Oi`）/ **`app-scroll`（壁纸轮播设置，`images/image-3.png`，对应 `ius0K` 里 `hT1PW` 那块矩形）**。三张底图都是设计稿里的窗口截图，所以视图本身是**位图**，不做内部控件重建。
- **入口与视图的对应关系**：**三个「查看更多」入口跳转完全一致**——锁屏 `BMgDr`、挂件 `UcQCx`、入口浮窗 `DqAiM` 一律落到 `app-lib`（壁纸库列表页），统一走 `goLibrary()`；点任一格壁纸 / 排行榜格子 → `app-detail`；设置中心的「设置壁纸轮播」（`LXYeV`）→ `app-scroll`。`openApp(view)` 接受可选视图名（点击事件对象会被 `typeof view === 'string'` 挡掉）。
- **`goLibrary()` 不给已开着的窗口重新播启动动画**：窗口本来就是开的时候（`state.appPhase === 'open'`，即 `DqAiM` 这类入口浮窗所在的库页 / 详情页 / 设置页）直接切 `appView` 并收起浮窗，窗口**全程不消失**；只有窗口原本关着（锁屏 `BMgDr`、桌面挂件 `UcQCx`）时才走 `openApp('library')` 的三拍启动动画。否则从详情页点浮窗胶囊会「先收起再重开」闪一下，而且在详情页 / 设置页点它只会回到原页、看起来像没反应。
- **壁纸库窗口**：`QNMlM`「壁纸频道」/ `ia7Oi`「壁纸详情页」里都没有内嵌的 `llYsS`，取而代之的是 `yKmw8`（1060×680 @ 270,160，`r6`，内容为 `images/image-1.png`），加上两页各自右上角那枚 `uF7kO` / `vpmOx` 触发、位置与桌面完全一致（380×397 @ 1200,68）的壁纸助手浮窗（画板节点 `aYhHd` / `b7yHN`，由 `llYsS` 整棵拷贝而来，是两页的最上层子节点）——即截图里压在窗口右上的那块。demo 里窗口对应一个绝对定位的 `.desk-app`，`state.appPhase`（`closed` / `launching` / `open`）驱动；`Esc` 或点击窗口外可关闭。
- **浮窗与窗口互不排斥**：`.assist` 的 `z-index:20` 压在 `.desk-app`（`z-index:10`）之上，两块可以同时出现。只有**唤起过程**（启动页那 760ms）里浮窗保持收起，免得盖住启动动画。浮窗默认仍是「hover 展开 / 移开 180ms 收起」，库页与详情页上额外支持点击钉住（`state.assistPin`），钉住后移开光标不收起；关窗时一并复位。
- **客户端唤起三拍**（`openApp()`）：
  1. `0ms` — `setScreen('desktop')` 落到桌面（挂件是 hover 态，此时自然是收起的），窗口完全不可见（`opacity:0`、`scale(.955)`）；
  2. `320ms` — 加 `.launching`：窗口淡入并放大到 `scale(.986)`，**露出的是启动页**（`#F7F8FA` + 蓝色旋转指示 + 「正在启动壁纸库…」）；
  3. `760ms` — 加 `.on`：`scale(1)` 落定，启动页 220ms 淡出，壁纸库内容浮现。
  整个过程用 `appTimers` 记录，`closeApp()` 会 `clearAppTimers()`，所以在动画中途关闭不会漏掉后续那一拍。
- 两枚「显示切换」的悬停提示现在分别是「显示 / 隐藏锁屏小组件」与「壁纸助手 · 壁纸入口」；`RtmAE`（桌面图标）、`fjrXH`（任务栏）与 `G7FiM`（系统托盘）连原生 `title` 提示都不带，保持纯静态。
